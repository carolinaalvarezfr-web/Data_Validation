====================================================================
PRIMARY COMPARISON RULE
====================================================================

For every comparison performed, calculate:

Difference = Latest Version Value − Older Version Value

This calculation rule must be applied consistently throughout the entire analysis unless otherwise specified.


====================================================================
VISIBLE VALUE EXTRACTION RULES
====================================================================

Before performing any mapping, comparison, reconciliation, or calculation:

• Use only the numeric values visibly displayed within the actuarial exhibits, tables, sections, and coverage reporting blocks.

• Treat the displayed value as the official source value for all comparisons.

• Compare only the numbers visible within the coverage exhibits.

• Do NOT use underlying workbook logic as a comparison input.

• Ignore completely:

  • Cell formulas
  • Formula dependencies
  • Workbook calculations
  • External workbook links
  • Internal workbook links
  • Hyperlinks
  • Named ranges
  • VBA code
  • Macros
  • Pivot tables
  • Pivot cache information
  • Data connections
  • Queries
  • Comments
  • Notes
  • Hidden rows
  • Hidden columns
  • Hidden worksheets
  • Metadata

• If a displayed value differs from the value generated by a formula, link, reference, or workbook calculation, use only the value visibly displayed in the worksheet.

• All comparisons must be based exclusively on visible reported values.

• Under no circumstances should formulas, links, references, workbook calculations, or hidden logic be used as comparison inputs.

====================================================================
COVERAGE DATA EXTRACTION RULES
====================================================================

When reviewing the workbooks:

• Extract information only from the actuarial exhibits, tables, sections, and reporting blocks belonging to each coverage.

• Limit all comparisons and calculations to the values visibly contained within those coverage exhibits.

• Ignore information located outside of the coverage reporting exhibits, including:

  • Technical calculation worksheets
  • Formula support areas
  • Mapping tables
  • Validation worksheets
  • Calculation engines
  • Data import worksheets
  • Staging worksheets
  • Intermediate calculations
  • Supporting work areas

• Coverage reporting exhibits always take precedence over any supporting calculations elsewhere in the workbook.

• Only the visible numbers contained within each coverage exhibit are eligible for comparison.

• Do not use values originating from linked cells, referenced cells, formulas, pivot logic, workbook calculations, or supporting schedules outside the coverage reporting tables.

====================================================================
ACTUARIAL MAPPING AND MATCHING LOGIC
====================================================================

Before calculating differences:

1. Review every worksheet in both workbooks.

2. Identify and map:
   - Worksheets
   - Exhibits
   - Tables
   - Sections
   - Data blocks
   - Coverages
   - Accident years
   - Calendar years
   - Policy years
   - Underwriting years
   - Metrics
   - Row labels
   - Column labels

3. Prioritize matching exhibits based on:
   - Actuarial meaning
   - Business context
   - Reporting purpose
   - Table structure
   - Naming similarity

4. Do NOT rely exclusively on worksheet position.

5. If content has been moved to another worksheet or another section, attempt to identify the logical match.

6. If worksheet names differ slightly:
   - Compare structure
   - Compare headers
   - Compare coverage names
   - Compare reporting purpose
   - Compare surrounding tables

7. Use best-match mapping whenever minor naming differences exist.

Examples:
   "Ultimate Claims" vs "Ultimate Losses"
   "BI Coverage" vs "Bodily Injury"
   "Property Total" vs "Total Property"

These should be matched whenever business meaning clearly indicates equivalence.

8. Document any assumptions used during matching.
